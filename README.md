# Comnview for Cursor

[Comnview](https://comnview.com) is where clients review websites, images and PDFs by pinning comments right where they mean them. This plugin connects Cursor to your Comnview account, so you can work through that feedback next to the code.

## What it does

- Read the open comments on a project, with what each pin points at.
- Fix the source, upload the corrected file as a new version, reply to each thread and resolve the ones that are done.
- Run a design audit of a public web page, screens or a PDF, and pin each issue where it is.

Cursor asks before it posts, uploads, deletes or sends anything. Comment texts come from your reviewers and are treated as feedback, never as instructions.

## Setup

Install the plugin and connect Comnview when Cursor asks. You sign in on comnview.com and choose what the connection may do: read only, read and reply, or full access. Disconnect any time in Profile > Agents on comnview.com.

Requires a Comnview account with AI agent access. Help: https://comnview.com/agents
